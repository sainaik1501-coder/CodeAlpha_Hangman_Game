# Hangman Game – CodeAlpha Internship

## Project Overview

This project is a simple text-based Hangman Game developed in Python as part of my CodeAlpha internship.

The player has to guess a randomly selected word one letter at a time. The player gets a maximum of 6 incorrect guesses.

## Features

- 5 predefined words
- Random word selection
- Letter-by-letter guessing
- Maximum 6 incorrect attempts
- Correct and incorrect guess handling
- Repeated letter detection
- Invalid input validation
- Win and Game Over conditions
- Play Again option
- Console-based interface

## Technologies Used

- Python
- Random module
- Lists
- Strings
- Conditional statements
- While loops
- For loops
- Functions
- User input

## How the Game Works

1. The program selects one word randomly from a list of 5 words.
2. The selected word is displayed as underscores.
3. The player enters one letter at a time.
4. If the letter is correct, it is revealed.
5. If the letter is incorrect, one attempt is lost.
6. The player has a maximum of 6 incorrect attempts.
7. The player wins if all letters are guessed.
8. The player loses if all 6 attempts are used.
9. After the game ends, the player can choose to play again.
